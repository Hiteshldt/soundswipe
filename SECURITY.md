# Security

SoundSwipe has no network service or analytics. Audio is processed locally in memory. Capture access is granted and revoked through macOS System Settings.

Report a vulnerability privately through [GitHub private vulnerability reporting](https://github.com/Hiteshldt/soundswipe/security/advisories/new). Do not post exploit details or personal data in a public issue.

Never include captured private audio, credentials, or full personal system logs in reports.
